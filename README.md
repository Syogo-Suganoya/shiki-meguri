# シキめぐり

冠婚葬祭レンタル × 移動エージェントです。

衣装レンタルの「借りるまで」しかなかった体験を、**衣装選び → 受取地最適化 → 当日の逆算動線 → 返却**まで
一気通貫でエージェントが仕切ります。

## 画面の流れ

予定を入れてから当日を迎えるまでの、実際の画面です。

### 1. 式の予定を入れる

種別・日時・会場の最寄り駅・出発する駅を選びます。誰の式かは訊きません。

![式の予定を入力するフォーム。式の種別、開式の日時、会場の最寄り駅、出発する駅を選ぶ](web/shots/01-plan.png)

### 2. 内容を確かめる

登録する前に一度見せます。

![入力した予定の確認画面。種別・開式・会場・出発する駅が並び、この予定で始めるボタンがある](web/shots/02-check.png)

### 3. 衣装をえらぶ

式の区分に合う候補を、費用の安い順に並べます。えらんでも、この時点ではまだ予約は入りません。

![衣装の候補が3件並ぶ画面。名前・色・サイズ・事業者・料金が出ている](web/shots/03-outfit.png)

### 4. 金額を確かめて承認する

受取場所と出発時刻、内訳と合計を見て承認します。ここで初めて予約が入ります。
（デモ版ではレンタル事業者は架空です）

![確認画面。受取場所と当日の出発時刻、レンタル料と受取手数料の内訳、合計金額、承認して確定するボタン](web/shots/04-confirm.png)

### 5. 当日の流れが決まる

開式から逆算した一日が出ます。「いま」の位置が入るので、どこまで進んだかが分かります。

![当日の流れ。出発から受取・着替え・移動・開式・返却期限までが時刻つきで並ぶ](web/shots/05-day.png)

### 6. あとは「AIに相談」から

右下のボタンでいつでも開けます。返却期限の注意もここに届きます。

![右側に開いた「AIに相談」のサイドバー。受付から予約確定までのやりとりが並んでいる](web/shots/06-chat.png)
